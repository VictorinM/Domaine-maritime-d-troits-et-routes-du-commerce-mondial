# Le domaine maritime, détroits et routes du commerce mondial

Une carte web qui montre où se joue le commerce par la mer. Les détroits stratégiques, les grandes routes maritimes et les principaux ports, sur un fond sombre lisible.

Près de 90 pour cent du commerce mondial passe par la mer, et tout ce flux se concentre sur quelques passages étroits. La carte rend cette idée visible d'un coup d'oeil, et replace les grands ports et les routes autour de ces points de passage.

## Ce que montre la carte

Les détroits stratégiques, Ormuz, Malacca, Suez, Bab el Mandeb, Panama, Gibraltar, le Bosphore, le Cap de Bonne Espérance, le détroit de Taïwan et les détroits danois. Au clic, chacun donne son rôle et un ordre de grandeur.

Les grandes routes maritimes, de l'Asie vers l'Europe par Suez, du Golfe vers l'Asie pour le pétrole, le transpacifique, le transatlantique, et la route de contournement par le Cap.

Les ports majeurs du monde, les plus importants, en points clairs.

On peut afficher ou masquer chaque couche.

## Le point de vue

Pour suivre les navires, on s'appuie sur l'AIS, le signal que les bateaux émettent. Mais tous ne l'émettent pas, et certains l'éteignent volontairement. C'est là que la détection par radiofréquence depuis l'espace prend tout son sens, elle voit les navires restés silencieux. La carte sert à poser ce décor, la connaissance du domaine maritime.

## Les données

Les ports viennent de Natural Earth. Les chiffres des détroits sont des ordres de grandeur, issus de sources publiques, EIA et UNCTAD. Les routes sont schématiques, elles montrent les grands axes, pas des tracés précis. Le fond de carte est le Dark Gray Canvas d'Esri.

## Comment l'ouvrir

Ouvrez index.html dans un navigateur, avec une connexion internet. Pour une version en ligne, publiez le fichier sur un hébergement statique, GitHub Pages par exemple.

## Le dépôt

- `index.html`, la carte complète. Un seul fichier, données comprises.
